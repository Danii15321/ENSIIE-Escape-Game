# Médias du site Évry 2026

Photos des deux repères, transmises par le porteur du projet le 16 octobre 2026. Elles ont été réduites à 1280 px de côté maximal (qualité JPEG 82, métadonnées EXIF retirées) pour la préparation hors ligne. Elles sont déclarées dans `../site.json` (`landmarks.O1.photos`, `landmarks.O2.photos`) et affichées **seulement dans le secours** du repère, car elles révèlent la valeur à observer.

Les trois vues d’O2 montrent trois salles distinctes, ce qui évite un double comptage. Aucune ne montre de visage ni de document nominatif. Avant publication, compléter l’auteur, la date et l’accord de diffusion dans le dépôt public.

Pour ajouter une photo : déposer le fichier ici (jpg, jpeg, png ou webp, 1280 px maximum), puis le déclarer dans `site.json` avec un texte alternatif. `npm run check:content` refuse une photo déclarée mais absente.
